# 成語插圖原圖與審核封存

此分支只保存原始 PNG、來源與逐檔審核／提示紀錄，以及對應索引。網站仍由 main 分支提供。

- `originals/`：依 SHA-256 命名，同一原圖只保留一份，包含歷史稿及退稿，不能因在此封存就視為已通過。
- `index.json`：原圖雜湊、原始來源、檔案大小、網站成語編號與紀錄對照。
- `records/reviews/`、`records/prompts/`：歷史逐檔紀錄去重保留。
- `records/status/`：每個網站詞條的原圖與審核保存狀態；`index.json` 直接指向目前採用的逐檔紀錄。網站索引與待辦以 main 為唯一入口，不另複製。
- `records/source*.json`：封存前遠端分支與 ZIP 成員來源清單。
- `coverage.json`：原圖與歷史審核紀錄的缺口。缺少紀錄不會補造通過證明，供後續重新審視。

所有來源均從 GitHub 可達歷史與現有雲端原圖檢查；ZIP 容器不另保存，原圖與 JSON 內容已解出並核對。
