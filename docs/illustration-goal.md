# 全量插圖自動接續目標

依使用者授權，完成全站尚未製作的成語插圖。沿用鉛筆手繪線條、柔和水彩、彩色鉛筆疊色與米白紙紋；能準確表意時採現代情境，否則保留典故或自然場景。

最新詞義修正：優先呈現當代常用的引申義，不能只因字面可畫就用字面替代寓意。例如「入木三分」應表現評論深刻中肯、分析直指核心；墨跡滲入木板的版本已依使用者回饋撤換。生成前先確認場景能表現詞義的關鍵因果或特徵。

- 只呼叫對話提供的內建圖片工具，不設定或呼叫另行計費的圖片 API，不新增 API 金鑰或付費服務。
- 工具若回報額度不足、需額外付費或無法繼續，保存已完成進度並將自動目標標為 blocked；不要改用付費 API 或要求使用者逐批確認。
- `data/illustrations.json` 是已完成的唯一依據。每次先執行 `python3 scripts/illustration_status.py`，跳過已有圖片；可依詞條編號由小到大處理剩餘詞條。
- 先讀教育部原始詞義，再自行設計原創場景，不修改教育部原文，不引用第三方插畫、品牌或既有角色，也不指定模仿特定創作者。
- 每張生成後檢視畫面與詞義，替代文字須符合實際畫面且不包含完整成語答案。用 `scripts/add_illustration.cjs` 登錄 WebP 與原圖雜湊，原 PNG 保留。
- 本次自動接續的完整畫風與場景提示保存於 `docs/illustration-prompts.json`，各項可以有自己的 `style_prompt`；沒有時使用該檔案的共用畫風。
- 每批保存新增圖片和提示紀錄，更新 `sw.js` 的版本，執行狀態檢查與有意義的圖片／題庫驗證。保留既有檔案與使用者變更，不重新套用已發布的舊變更。
- 批次只是保存與驗證的單位。整體目標仍未完成時由目標機制繼續，不要求使用者回覆「繼續」。只有全量完成或實際外部阻擋時才停止目標。
- 本目標授權產圖與保存，不發布環境，也不自行推送 GitHub、合併 PR 或部署網站。

現有工作區為 `/workspace/chengyu`。若需網站測試，先確認本機 8000 port 是否已有自己的測試伺服器；沒有時從儲存庫根目錄執行 `python3 -m http.server 8000 --bind 127.0.0.1`。完整整合檢查為 `node tests/illustrations.cjs`；不要把尚未跑過的測試記成通過。
